# Portfolio 2: Query Processing and Optimisation

This folder is for the work in this part of the ShopFlow database portfolio.

Work will be added here as it is built and tested. The README will be updated with the steps to run the work, the results, and the evidence needed for the assignment.

## Assumptions
Query 4 defines low stock as 15 units or fewer. This is a benchmark business rule, not a universal threshold.



Query 5 treats confirmed, shipped and delivered orders as completed for this report. You can refine that business definition later.



Query 3 measures successful payment amounts by order month. It is not a full accounting revenue-recognition model.



The generated timestamps and payment records are synthetic.
